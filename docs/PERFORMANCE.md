# 로컬 성능 측정

측정일: 2026-11-05. Windows의 Node.js 24.22.1에서 현재 파서·검색 함수를 실행한 결과다. Android 브라우저나 RTL의 성능 결과가 아니다.

개인 사전은 로컬 파일에서만 읽었다. 원문·파일명·검색 결과 행을 보고서, 공개 저장소, CI 또는 RTL에 복제하지 않았다.

| 항목 | 측정값 |
| --- | --- |
| 사전 규모 | 134,020행 / 25,852,780바이트 |
| CSV 파싱 | 194ms |
| 검색용 문자열 준비 | 369ms |
| 검색 표본 | 태그·한글·결과 없는 검색을 섞은 5개 검색어 × 5회 |
| 검색 p50 | 22.85ms |
| 검색 p95 | 73.88ms |
| 측정 프로세스 RSS | 약 457MiB |

시간은 입력 대기 120ms, 파일 읽기, IndexedDB 저장, 브라우저 UI 렌더링을 포함하지 않는다. RSS는 원본 버퍼·사전 행·검색용 문자열·Node 런타임을 포함한 프로세스 값이며 모바일 앱 메모리 사용량으로 해석하지 않는다. 단일 PC 실행 결과로 기기 성능 목표 충족을 선언하지 않는다.

실제 Android 기기에서 가져오기 전체 시간, 검색 p50/p95, 메모리와 키보드 입력 반응을 별도로 측정해야 한다. 원격 공유 기기에는 같은 규모의 합성 데이터만 사용한다.
