# 구현 순서와 검증 계획

기준일: 2026-11-05. 모든 구현 항목은 아직 미착수 상태다. 아래 항목은 앱 테스트가 통과했다는 보고가 아니다. 테스트 담당과 환경 요청은 [TESTING.md](TESTING.md)를 따른다.

## 1. 착수와 도구 선택

- [ ] 주 검증 대상인 Android Chrome의 실제 기기 또는 에뮬레이터 접근 가능 여부와 버전을 기록한다. 환경이 없으면 요청사항으로 남긴다.
- [ ] 삼성 인터넷 수동 테스트 항목을 작업자/관리자에게 제공하고 피드백을 별도로 추적한다.
- [ ] 정적 클라이언트용 언어·빌드 도구·CSV 파서·테스트 도구를 선택하고 버전을 고정한다.
- [ ] 화면, CSV 처리, 순수 검색, 저장 어댑터의 경계를 만든다.
- [ ] 실행·검사·빌드 명령을 README에 기록하고 잠금 파일을 관리한다.
- [ ] 프로젝트 하위 경로를 사용할 수 있도록 배포 base 설정을 준비한다.

완료 기준: 개인 CSV 없이 앱을 실행하고 긍정·부정 원문을 편집할 수 있다.

## 2. 사전 가져오기와 검색

- [ ] 합성 예제와 헤더·BOM·인용 쉼표·인용부호·빈 설명·잘못된 행·치명적 형식 오류를 검증한다.
- [ ] Worker 파싱과 진행/취소, IndexedDB 저장, 트랜잭션 교체를 구현한다.
- [ ] 여러 사전 보관과 하나의 활성 사전 선택을 구현한다.
- [ ] 태그·설명 검색, 공백 보정, 유형 필터, 정렬, 결과 상한을 구현한다.
- [ ] 한글 IME 조합과 오래된 검색 응답의 역전을 검증한다.
- [ ] 태그 내부 공백과 설명의 `<인원>`·인용부호가 보존되는지 확인한다.

완료 기준: 명세 A01~A03을 통과하고, 실패한 가져오기가 기존 사전을 바꾸지 않는다.

## 3. 편집·기록·라이브러리

- [ ] 별도 검색창과 마지막 편집기/선택 범위를 연결한다.
- [ ] 비어 있는 편집기, 문장 끝, 선택 범위, 쉼표·줄바꿈 경계 삽입을 검증한다.
- [ ] 같은 편집기 내 사용 중 표시와 중복 방지를 구현한다.
- [ ] 검색/기록 전환, 실제 삽입 성공 집계, 최근순·1,000개 제한, 삭제와 재사용을 구현한다.
- [ ] 기록에서 다른 삽입 대상으로 전환해도 정확한 편집기를 변경하는지 확인한다.
- [ ] 초안 자동 저장과 저장 실패 표시, 앱 전환 후 복원을 구현한다.
- [ ] 저장 프롬프트, 즐겨찾기, 태그 묶음과 사전 수명 분리를 구현한다.
- [ ] 복사와 실패 시 수동 선택을 구현한다.

완료 기준: 명세 A04~A08을 통과하고, 태그 칩이나 가중치 자동 처리가 추가되지 않는다.

## 4. JSON 백업·복원과 PWA

- [ ] 스키마 버전 1의 JSON 내보내기와 전체 복원을 구현한다.
- [ ] 초안·프롬프트·즐겨찾기·태그 묶음·기록·설정을 왕복 복원한다.
- [ ] 문법 오류·타입 오류·다른 앱 ID·미지원 버전·참조 오류에서 기존 데이터가 보존되는지 검증한다.
- [ ] 현재 CSV 보관소를 보존하고, 지문이 맞는 사전만 연결한다.
- [ ] manifest, 아이콘, Service Worker와 앱 리소스 캐시를 구현한다.
- [ ] 편집 중 업데이트 알림과 저장 후 적용을 구현한다.
- [ ] 오프라인 가져오기·검색·편집·복사·재실행과 DB 마이그레이션 실패 경로를 검증한다.

완료 기준: 명세 A09~A11을 통과한다.

완료 기준: A01~A13의 결과와 남은 제한을 기록하고 Android Chrome에서 필수 흐름을 검증한다. Android 환경 미확보 시 실제 테스트 결과를 미검증으로 남기고 필요한 환경을 요청한다. 삼성 인터넷은 작업자/관리자의 수동 검증 결과와 제안 사항을 별도로 관리하며, 에이전트가 삼성 인터넷을 자동 조작할 수 없다는 이유로 구현 작업을 중단하지 않는다. 수동 테스트 전에는 삼성 인터넷 호환성을 검증 완료로 표시하지 않는다. 원격 프로그램의 PC 전달 기능은 재검증 범위에 포함하지 않는다.

## 6. 테스트 데이터와 결과 기록

자동화에는 합성 데이터만 사용한다. 규모 테스트 데이터가 필요하면 공개 예제의 의미와 무관한 합성 태그·설명을 생성한다. 실제 개인 CSV를 테스트 저장소나 CI에 업로드하지 않는다.

검증 결과에는 실행 날짜, 커밋, 기기·OS·브라우저 버전, 사전 행 수·크기, 측정 조건, 통과/실패, 재현 가능한 현상을 기록한다. 실데이터 원문·화면·백업은 공개 결과에 포함하지 않는다.

문서만 있는 현재 단계에는 런타임 build/test 명령과 Pages 배포 워크플로를 미리 생성하지 않는다. 실제 앱 도구가 준비된 단계에 맞춰 추가한다.
