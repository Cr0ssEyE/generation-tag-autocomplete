# 구현과 검증 상태

기준일: 2026-11-06. 앱 0.3.0의 UI/UX 개선 구현과 자동 검증을 완료했다. 신규 Android 실기기 회귀 검증은 대기다. 기존 0.2.0 관리자 결과, 자동 검증과 신규 기기 검증을 구분한다.

## 0.2.0 구현 완료

- [x] TypeScript/Vite/Papa Parse, 잠금 파일, 실행·테스트·빌드 명령.
- [x] Worker 파싱·검색·진행·취소와 IndexedDB 사전 저장·선택·교체·삭제.
- [x] CSV 헤더·BOM·인용 필드·잘못된 행·중복 검증과 공백 보정 검색.
- [x] 긍정/부정 전환, 현재 항목 자동완성, 커서·구분자·주변 원문 보존.
- [x] 수동 괄호·가중치 구문 보호, 이미 완성/사용 중 표시와 중복 방지.
- [x] 고정 주요 메뉴, 접이식 북마크·유형 탐색·기록 패널.
- [x] 초안 자동 저장, 다른 탭 충돌 방지, 삽입 취소, 복사와 수동 선택 대안.
- [x] 이름 저장, 북마크, 태그 묶음, 최근순 고유 태그 기록 1,000개.
- [x] JSON 검증·전체 복원·CSV 보관 유지·지문 연결.
- [x] manifest·아이콘·Service Worker·리소스 캐시·사용자 선택 업데이트.
- [x] 합성 데이터 자동 테스트와 GitHub Actions Pages 배포 설정.

## 0.2.0 기능 검증 완료

자동 테스트·데스크톱·에뮬레이터 결과와 관리자 실기기 결과는 [TESTING.md](TESTING.md)에 기록한다. 관리자 보고일은 2026-11-06이며, 환경은 갤럭시 S25·탭 A11+, Android Chrome·삼성 브라우저다.

- [x] 현재 구현의 자동 테스트 15개, TypeScript 검사와 프로덕션 빌드 통과.
- [x] 현재 항목 자동완성·긍정/부정 전환·고정 메뉴·보조 패널의 데스크톱 회귀 점검.
- [x] 관리자 수동 체크리스트에 따른 Android Chrome·삼성 브라우저 기능 검증. 한글 입력·커서·키보드·삽입·기록·복사·초안 복원 포함.
- [x] 관리자 보고에 따른 사전 가져오기·취소·전환, JSON 내보내기·불러오기·잘못된 양식 거절 확인.
- [x] 관리자 보고에 따른 홈 화면 추가·오프라인 재실행·업데이트 흐름 확인.

보고된 기능 결함이 없어 0.2.0 기능 구현을 마무리했다. 새 도구 설치나 RTL 재예약 요청은 없다. 전체 수용 기준의 실측 검증과 성능 목표 달성을 모두 완료한 상태로 표시하지 않는다.

## 0.3.0 UI/UX 개선 작업

상세 계약은 [UI_UX_IMPROVEMENTS.md](UI_UX_IMPROVEMENTS.md)를 따른다. 코드와 자동 검증을 완료하고 실제 기기 검증 범위를 분리한다.

- [x] 대화에서 확정한 버튼 방식, 빈 부정 원문 교체, 미리보기 개별 복사, 지속 저장 변경 제외를 명세에 반영.
- [x] 120ms 입력 대기와 조합 중 후보 검색, 최신 대기 요청 처리. IME 후보 선택·후속 이벤트 경합의 합성 DOM 검증.
- [x] 양쪽 원문 미리보기·개별 복사·명시적 전체 교체. 취소·빈 원문·복사 거절·저장 실패·다른 탭 충돌의 DOM/저장 검증.
- [x] 기존 태그 찾기를 편집 화면 전용 측면 버튼 패널로 이동. 커서·연속 삽입·탭과 스크롤 상태의 DOM 검증과 실제 보이는 영역 기준 배치 구현.
- [x] 자동 테스트 26개, TypeScript 검사와 프로덕션 빌드 통과. 지연된 이전 사전 로드의 인덱스 덮어쓰기 방지 검증.
- [ ] 신규 U01–U14와 기존 A01–A15의 실제 Android Chrome 회귀 검증 및 관리자 삼성 브라우저 확인. 실제 IME·키보드·화면·복사·오프라인 동작 포함.
- [ ] 모바일 검색 계산·후보 표시 시간의 측정 결과 또는 미측정 범위를 기록. 대기 0ms 검색은 별도 판단.
- [x] 구현 결과·앱 버전·변경 기록과 신규 실기기 확인 목록 정리. 배포 실행 결과는 해당 커밋의 GitHub Actions에서 확인.

DB와 JSON 스키마 1은 유지했다. 컴퓨터 조작 도구의 Chrome URL 판별 실패로 이번 신규 화면 검증은 중단했으며, 합성 이벤트 결과를 실제 Android IME 통과로 표시하지 않는다. 추가 설치를 요청하지 않는다.
