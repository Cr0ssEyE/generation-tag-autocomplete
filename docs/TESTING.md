# 테스트 담당과 환경 요청

기준일: 2026-11-05. 앱 0.2.0의 구현·검증 상태를 기록한다. 이전 0.1.0의 S25 실기기 결과와 이번 UI의 회귀 검증은 구분한다.

## 1. 담당과 판정 기준

| 대상 | 담당 | 기준 |
| --- | --- | --- |
| 파싱·검색·저장 로직과 데스크톱 Chromium 점검 | 에이전트 | 합성 데이터로 자동화하고 검증 범위를 명시한다. |
| Android Chrome | 주 개발·검증 대상. 접근 가능한 실제 단말 또는 에뮬레이터에서 에이전트 검증, 필요 시 작업자 지원 | 실제 환경·버전을 기록한다. 모바일 화면 에뮬레이션만으로 Android 검증 완료를 선언하지 않는다. |
| 삼성 인터넷 | 작업자/관리자의 수동 테스트 | 문제점·개선사항을 제출하고 에이전트가 재현·수정·회귀 검증을 지원한다. |

에이전트의 삼성 인터넷 자동화 가능 여부는 구현 작업의 선행조건이 아니다. 수동 테스트를 수행하기 전에는 해당 브라우저를 미검증으로 표시한다. 프로젝트 관리자는 수동 테스트에서 발견한 문제의 우선순위와 출시 영향을 판단한다.

## 2. 현재 환경 요청 상태

2026-11-05 기존 설치 환경을 점검하고 가상 기기를 실행했다. 추가 설치 없이 에뮬레이터가 Android 홈 화면까지 부팅했고 ADB 연결을 확인했다. 이 문서의 기존 AVD 환경 점검과 아래 앱 검증 결과를 구분한다.

### 2.1 확인된 환경

| 항목 | 확인 결과 |
| --- | --- |
| Android Studio | 기존 설치 확인 |
| SDK | `D:\AndroidSDK` |
| Android Emulator | `36.1.9.0` |
| ADB Platform Tools | `36.0.0-13206524` |
| 가상 기기 | 기존 `Pixel_6_Pro`, x86_64, Google APIs 이미지 |
| Android | Android 16 / API 36 |
| VM 가속 | AEHD 2.2 사용 가능 |
| 부팅 | `sys.boot_completed=1`, 부팅 애니메이션 종료, 홈 화면 확인 |
| ADB 연결 | 점검 당시 `emulator-5554`, 상태 `device` |
| Chrome | `133.0.6943.137` 설치 및 프로세스 실행 확인 |
| Chrome 초기 상태 | 첫 실행 설정 화면(`FirstRunActivity`)에 머무름 |
| Chrome 웹페이지·CDP | 첫 실행 설정 이후 확인 필요. 현재 검증 완료로 표시하지 않음 |

기존 AVD를 그대로 실행했다. 가상 기기 초기화, 시스템 이미지 교체, 추가 SDK 설치, BIOS 또는 Windows 가상화 설정 변경은 수행하지 않았다. SDK/AVD 경로 환경 변수는 진단 프로세스에만 설정했으며 사용자 전역 환경 변수를 변경하지 않았다.

### 2.2 남은 준비 사항

- Chrome 첫 실행 설정을 완료한 뒤 실제 웹페이지 로딩과 원격 디버깅을 확인한다.
- 설치된 Chrome 133을 최신 안정판 검증 환경으로 취급하지 않는다. 주 검증 전에 브라우저 업데이트 경로와 버전을 확인한다.
- 현재 AVD는 Google APIs 이미지이며 `PlayStore.enabled=false`다. Play Store 사용이나 계정 로그인을 전제로 업데이트 절차를 확정하지 않는다. 업데이트를 위해 별도 이미지 또는 패키지가 필요하면 구체적인 작업과 용량을 확인해 요청사항으로 남긴다.
- 에뮬레이터의 기능·성능 결과와 실제 휴대폰 결과는 구분해 보고한다.

| 조건부 요청 | 필요한 시점 | 현재 상태 |
| --- | --- | --- |
| Android 에뮬레이터 접근 | 모바일 동작·PWA 검증 전 | 기존 AVD 부팅·ADB 연결 확인 |
| Android Studio/SDK/AVD 추가 설치 | 기존 환경을 사용할 수 없을 때 | 현재 필요 없음 |
| Chrome 첫 실행 설정·버전 정비 | 웹페이지·CDP 및 최신 안정판 검증 전 | 준비 필요 |
| ADB 포워딩·Chrome 원격 디버깅 | 브라우저 자동화 연결 전 | 첫 실행 설정 후 확인 예정 |
| 삼성 인터넷 수동 검증 | 검증 가능한 앱 버전 제공 후 | 작업자/관리자 수행 예정 |

### 2.3 기존 환경 실행과 확인

로그인한 Windows 사용자 컨텍스트에서 기존 SDK를 사용한다. 가상 기기 이름과 실행 중인 기기의 serial은 매번 확인한다.

```powershell
& 'D:\AndroidSDK\emulator\emulator.exe' -list-avds
& 'D:\AndroidSDK\emulator\emulator.exe' -accel-check
& 'D:\AndroidSDK\emulator\emulator.exe' -avd Pixel_6_Pro
```

다른 터미널에서 확인한다.

```powershell
& 'D:\AndroidSDK\platform-tools\adb.exe' devices -l
& 'D:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 shell getprop sys.boot_completed
```

실제 단말 원격 디버깅도 후속 선택지다. Android Studio 없이 Chrome DevTools로 실기기를 연결할 수 있다. 단말 연결·디버깅 권한 허용 등이 필요하면 해당 시점에 요청사항으로 남긴다.

## 3. 삼성 인터넷 수동 테스트 체크리스트

- [ ] 합성 예제 가져오기, 취소, 사전 전환이 동작한다.
- [ ] 한글 조합 입력과 키보드가 열린 상태에서 후보 선택·본문 편집이 원활하다.
- [ ] 긍정/부정 삽입 대상과 커서가 보존된다.
- [ ] 기록 재사용, 사용 중 표시, 중복 삽입 방지가 동작한다.
- [ ] 양쪽 프롬프트 복사와 실패 시 수동 복사가 동작한다.
- [ ] 앱 전환과 재실행 뒤 초안이 복원된다.
- [ ] 홈 화면 추가·오프라인 재실행·앱 업데이트 흐름을 확인한다.
- [ ] JSON 백업·전체 복원·잘못된 백업 거절이 동작한다.


공개 이슈와 화면 예제에는 합성 데이터만 사용한다. 개인 CSV, 실제 프롬프트, 백업 원문은 올리지 않는다. 실데이터에서만 발생하면 우선 크기·행 수·오류 유형 등 집계 정보로 전달하고 합성 재현 예제로 좁힌다.

## 6. 앱 구현 및 실행 결과 (2026-11-05)

### 6.1 이전 0.1.0 / 커밋 252e835

- 공개 Pages 빌드·배포 성공. 합성 11행만 번들에 포함했다.
- 데스크톱 Chromium: 예제 가져오기, 설명 검색, 양쪽 독립 삽입, 기록·북마크·이름 저장·묶음, 재실행 복원, JSON 미래 버전 거절 및 합성 백업 전체 복원·CSV 보관 유지 확인. 백업 다운로드 완료는 제어 연결 끊김으로 확정하지 못했다.
- Samsung RTL Galaxy S25 SM-S931N_KR2 / Android 16 / One UI 8.5: Chrome 계정 없이 공개 Pages 접속, 예제 11행 가져오기, 삼성 키보드에서 ‘여자1명’ 조합·확정, 1girl 검색, 긍정 삽입·사용 중 표시, Android ‘Copied’ 표시 확인. Chrome 정확한 버전은 수집하지 못했다.
- RTL은 초기 검은 화면·Getting ready to restart가 반복되었고 이후 재접속으로 사용했다. 예약·서비스 준비 시간은 앱 장애로 분류하지 않는다.

### 6.2 현재 0.2.0

- 순수 함수·CSV·백업·저장 트랜잭션 테스트 15개 통과, TypeScript 검사·프로덕션 빌드 성공. fake-indexeddb 테스트는 실제 브라우저 저장 공간 부족 시험을 대체하지 않는다.
- 데스크톱 Chromium: 가운데 blue e 항목만 blue eyes로 대체하고 이웃 원문 유지, 긍정/부정 원문 전환, 한글 설명 후보 선택, 북마크, 유형만 선택한 탐색 확인.
- 데스크톱 390×844 반응형 화면: 스크롤 후 주요 메뉴 top=0 확인. 이 결과를 Android IME 검증으로 취급하지 않는다.
- 저장 안정성: 사전 저장 도중 동기 복제 오류 시 전체 롤백, 사전 삭제와 초안·북마크 수명 분리, 오래된 다른 탭의 덮어쓰기 거절을 자동 테스트했다.
- 이전 UI의 오류 안내가 정상 백업 미리보기 뒤 남던 문제를 수정했다.

### 6.3 남은 확인

- 현재 0.2.0을 Android Chrome에서 회귀 검증: IME·키보드 높이·후보 탭·커서 이동·두 프롬프트 전환.
- 기기 파일 선택·교체·취소, JSON 다운로드/복원, 홈 화면 설치·오프라인 재실행·업데이트 적용.
- 실제 단말에서 약 134,020행 규모 성능 p50/p95·메모리, 저장 공간 부족·지속 저장 거절. RTL에는 합성 데이터만 사용한다. 개인 CSV는 로컬 승인 환경에서만 측정한다.
- 런타임 네트워크에서 개인 데이터가 전송되지 않는지 검사. 소스·배포 파일 검토만으로 전체 네트워크 검증 완료를 선언하지 않는다.
- 삼성 인터넷은 관리자 수동 테스트 전 미검증.

기존 Pixel 6 Pro AVD는 실행 중이며 Chrome 133의 첫 실행 설정이 필요하다. Chrome 133은 최신 안정판 검증으로 표시하지 않는다. RTL 추가 예약이나 새로운 도구 설치는 이번 UI 구현에 필수 조건이 아니다.

- Service Worker의 오프라인 셸·Worker 파일 응답, 다른 앱 캐시 보존, 사용자 업데이트 요청 전 대기를 VM 계약 테스트로 검증했다. 이 검사는 실제 기기 비행기 모드 검증을 대체하지 않는다.
