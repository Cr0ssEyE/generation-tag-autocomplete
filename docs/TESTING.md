# 테스트 담당과 환경 요청

기준일: 2026-11-05. 앱 구현 전이며 아래 항목은 실제 테스트 통과 보고가 아니다.

## 1. 담당과 판정 기준

| 대상 | 담당 | 기준 |
| --- | --- | --- |
| 파싱·검색·저장 로직과 데스크톱 Chromium 점검 | 에이전트 | 합성 데이터로 자동화하고 검증 범위를 명시한다. |
| Android Chrome | 주 개발·검증 대상. 접근 가능한 실제 단말 또는 에뮬레이터에서 에이전트 검증, 필요 시 작업자 지원 | 실제 환경·버전을 기록한다. 모바일 화면 에뮬레이션만으로 Android 검증 완료를 선언하지 않는다. |
| 삼성 인터넷 | 작업자/관리자의 수동 테스트 | 문제점·개선사항을 제출하고 에이전트가 재현·수정·회귀 검증을 지원한다. |

에이전트의 삼성 인터넷 자동화 가능 여부는 구현 작업의 선행조건이 아니다. 수동 테스트를 수행하기 전에는 해당 브라우저를 미검증으로 표시한다. 프로젝트 관리자는 수동 테스트에서 발견한 문제의 우선순위와 출시 영향을 판단한다.

## 2. 현재 환경 요청 상태

원격 저장소 생성과 첫 커밋을 만드는 현재 단계에는 Android Studio, SDK 또는 Android 단말의 추가 설정이 필요하지 않다. 이 단계에서 앱 실행·브라우저 테스트는 수행하지 않는다.

앱 구현 후 Android Chrome 검증 전에 다음 중 접근 가능한 경로를 확인한다.

1. Android 실기기와 Chrome. 필요할 때 Chrome DevTools 원격 디버깅을 연결한다. Android Studio 없이 실기기 원격 디버깅을 진행할 수 있다.
2. 실기기 접근이 어려우면 Chrome을 실행할 수 있는 Android 에뮬레이터. 필요 시 Android Studio/SDK/AVD 환경을 요청한다.

현재 실제 단말 연결, SDK/AVD 준비 여부와 에이전트 접근 가능 여부는 미확인이다. 설치·기기 연결·디버깅 권한 허용이 필요하면 해당 시점에 구체적인 요청사항으로 남긴다. 이미 설치된 환경이 있으면 재사용 가능 여부를 먼저 확인하고 중복 설치를 요청하지 않는다. 에뮬레이터의 성능 수치를 실제 휴대폰 성능으로 보고하지 않는다.

| 조건부 요청 | 필요한 시점 | 현재 상태 |
| --- | --- | --- |
| Android Chrome 실기기 또는 에뮬레이터 접근 | 모바일 동작·PWA 검증 전 | 환경 확인 예정 |
| Android Studio/SDK/AVD | 실기기 대신 에뮬레이터가 필요할 때 | 현재 필수 요청 없음 |
| ADB/기기 드라이버/원격 디버깅 연결 | 선택한 단말 연결 방식에 필요할 때 | 필요 여부 확인 예정 |
| 삼성 인터넷 수동 검증 | 검증 가능한 앱 버전 제공 후 | 작업자/관리자 수행 예정 |

## 3. 삼성 인터넷 수동 테스트 체크리스트

- [ ] 합성 예제 가져오기, 취소, 사전 전환이 동작한다.
- [ ] 한글 조합 입력과 키보드가 열린 상태에서 후보 선택·본문 편집이 원활하다.
- [ ] 긍정/부정 삽입 대상과 커서가 보존된다.
- [ ] 기록 재사용, 사용 중 표시, 중복 삽입 방지가 동작한다.
- [ ] 양쪽 프롬프트 복사와 실패 시 수동 복사가 동작한다.
- [ ] 앱 전환과 재실행 뒤 초안이 복원된다.
- [ ] 홈 화면 추가·오프라인 재실행·앱 업데이트 흐름을 확인한다.
- [ ] JSON 백업·전체 복원·잘못된 백업 거절이 동작한다.

## 4. 문제점과 개선사항 제안 양식

```text
종류: 오류 / 사용성 개선
검증한 앱 버전 또는 커밋:
기기 / Android 버전:
브라우저 이름 / 버전:
실행 형태: 일반 탭 / 홈 화면 실행
온라인 / 오프라인:
재현 절차:
기대 결과:
실제 결과:
반복 발생 여부:
영향과 제안:
```

공개 이슈와 화면 예제에는 합성 데이터만 사용한다. 개인 CSV, 실제 프롬프트, 백업 원문은 올리지 않는다. 실데이터에서만 발생하면 우선 크기·행 수·오류 유형 등 집계 정보로 전달하고 합성 재현 예제로 좁힌다.
