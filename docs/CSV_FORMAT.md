# CSV 규격과 검색 계약

기준일: 2026-11-04. 이 문서는 [작업 명세서](SPECIFICATION.md)의 CSV 관련 계약을 구체화한다.

## 1. 기본 형식

쉼표 구분 CSV이며 데이터 열은 정확히 4개다. UTF-8과 UTF-8 BOM을 지원한다. LF와 CRLF 줄 끝을 모두 허용한다. 파일 이름 확장자와 내용 검증을 함께 사용한다.

| 순서 | 의미 | 처리 |
| --- | --- | --- |
| 1 | 태그 | 삽입할 원본 문자열. 내부 공백, `@`, 괄호 등을 자동 변환하지 않는다. |
| 2 | 유형코드 | 0 이상의 정수. 알려진 코드와 알 수 없는 코드도 원래 값을 보관한다. |
| 3 | 태그카운트 | 0 이상의 안전하게 표현 가능한 정수. 정렬 보조 기준이다. |
| 4 | 설명 | 한글 설명·분류·키워드가 있는 원문 텍스트. 별칭 배열로 분해하지 않는다. |

현재 참조 사전은 헤더 없는 4열 형식이다. 첫 행을 임의로 헤더로 버리지 않는다. 선택적으로 다음 헤더 조합만 명시적으로 인식한다.

- `태그,유형코드,태그카운트,설명`
- `tag,category,count,description`

헤더 비교에는 BOM, 양끝 공백과 영문 대소문자만 보정한다. 첫 행의 숫자 변환 실패만을 이유로 헤더라고 판단하지 않는다.

설명 안의 쉼표와 줄바꿈은 CSV 표준의 인용 필드로 처리한다. 따옴표 안의 따옴표는 `""`로 표현한다. `split(',')`나 물리적 줄 단위 분할로 파싱하지 않는다.

```csv
1girl,0,1000,"[인물 > 인원수] 여성 캐릭터가 한 명 등장함. 키워드: <인원>, 여자 1명, 여성 한명"
blue eyes,0,900,"[외형 > 눈] 파란 눈. 키워드: 파란눈, 푸른 눈"
sign,0,150,"[소품 > 표지판] 표지판에 ""Hello"" 문구가 표시됨. 키워드: 간판, 표지판"
```

`[인물 > 인원수]` 같은 설명의 경로는 검색 가능한 설명 텍스트다. 유형코드 필터와 별도의 분류로 취급하며 첫 버전에서 트리 UI를 추출하지 않는다.

## 2. 검증과 오류 처리

| 상황 | 동작 |
| --- | --- |
| 빈 물리적 행 | 무시. 오류로 세지 않는다. |
| 열 수가 4개가 아닌 복구 가능한 행 | 행을 건너뛰고 오류 수와 이유를 표시한다. |
| 비어 있거나 공백뿐인 태그 | 해당 행을 건너뛴다. |
| 태그에 쉼표 또는 줄바꿈 포함 | 현재 프롬프트 구분자와 충돌하므로 해당 행을 지원하지 않는 값으로 보고한다. |
| 유형코드·카운트가 음수, 비정수 또는 안전 정수 범위 밖 | 해당 행을 건너뛴다. |
| 빈 설명 | 태그 검색용으로 허용하고 설명 없음으로 표시한다. |
| 같은 사전 안의 중복 태그 | NFC와 양끝 공백 제거 기준으로 비교해 첫 유효 행을 유지하고 중복 수를 표시한다. |
| 닫히지 않은 따옴표 등 레코드 경계를 신뢰할 수 없는 오류 | 가져오기를 중단한다. 기존 데이터를 보존한다. |
| UTF-8 해석 실패, 저장 용량 부족, 취소, 유효 행 0개 | 가져오기를 확정하지 않고 기존 데이터를 보존한다. |

가져오기 결과에는 전체 레코드 수, 유효·건너뛴·중복 수와 오류 이유별 개수를 표시한다. 오류의 위치와 이유를 확인할 수 있게 하되 실제 설명 전체를 콘솔·외부 로그에 기록하지 않는다. 치명적 오류를 임의로 문자 대체해 성공으로 처리하지 않는다.

태그와 설명의 원문은 보존한다. 비교용 키와 검색용 정규화 문자열은 별도로 관리한다. 입력 사전을 외부 인코딩 변환 서비스에 보내지 않는다.

## 3. 검색 예제

`samples/tags.example.csv`의 첫 행을 기준으로 한다.

| 검색어 | `1girl` 일치 | 조건 |
| --- | --- | --- |
| `1gi` | 예 | 태그 앞부분 |
| `여자 1명` | 예 | 설명 부분 문자열 |
| `여자1명` | 예 | 공백 제거 보조 검색 |
| `여성한명` | 예 | 공백 제거 보조 검색 |
| `인원수` | 예 | 설명의 분류 문자열 |
| `여성 1명` | 아니오 | 숫자·한글 수사 의미 변환 없음 |
| `여자 인원수` | 아니오 | 여러 단어 AND 검색 없음 |

`BLUE EYES`는 대소문자 보정으로 `blue eyes`를 찾는다. `blue_eyes`를 `blue eyes`로 자동 변환하지 않는다. 선택 시 출력은 항상 원본 태그다.

설명은 신뢰할 수 없는 일반 텍스트로 취급한다. `<인원>`과 인용부호를 그대로 보여주고 HTML 실행·링크 자동 열기 동작을 부여하지 않는다.

## 4. 공개 예제와 개인 사전

`samples/tags.example.csv`의 11개 행은 공개 데모와 검증을 위해 작성한 합성 예제다. 실제 개인 사전을 복제하거나 축약한 데이터셋으로 취급하지 않는다. 원문 인용 예제는 사용자가 대화에서 제공한 비민감 예시를 사용한다.

실제 사전은 단말에서 가져온다. 프로젝트 폴더의 개인 CSV를 자동 복사·번들·업로드하지 않는다. 공개 예제 사용도 사용자가 선택하는 동작으로 제공한다.

실제 단말 성능 검증은 승인된 로컬 사전을 사용해 수행하고 결과에는 행 수·바이트 크기·시간·메모리 같은 집계만 남긴다.
