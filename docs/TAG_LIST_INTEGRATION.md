# 편집 화면 태그 목록 통합 작업 명세서

- 기준일: 2026-11-12
- 상태: 앱 0.4.0 구현·자동 검증·데스크톱 Chrome 점검 완료. Android 및 삼성 키보드 확인 대기
- 기준 구현: 앱 0.3.1, 커밋 `e1842e0`
- 관련 문서: [전체 작업 명세서](SPECIFICATION.md), [0.3.x UI/UX 개선 명세](UI_UX_IMPROVEMENTS.md), [테스트 기록](TESTING.md)

## 1. 목적과 범위

프롬프트를 편집하면서 태그를 찾고 재사용할 수 있도록 편집기 아래의 자동완성 공간을 `태그 목록`으로 확장한다. `자동완성 / 북마크 / 기록` 세 탭이 목록 영역 하나를 공유한다. 편집 화면의 측면 `태그 찾기` 버튼, 오버레이, 닫기 동작과 별도 검색창을 제거한다.

검토 시안의 **세 탭 통합** 구성을 기준으로 한다. 기존 유형 탐색은 `자동완성` 탭의 `유형` 필터로 제공한다. 긍정/부정 탭은 편집 대상을, 태그 목록 탭은 표시할 목록을 선택한다. 상단 주요 메뉴, 편집기 복사·이름 저장·삽입 취소, 라이브러리의 북마크 관리와 프롬프트 미리보기는 기존 기능을 사용한다.

이 문서는 통합 구현에 적용할 변경 명세다. 0.3.x의 측면 패널 설명은 이전 구현 이력이다. 통합 화면의 동작과 신규 수용 기준은 이 문서를 적용하고 검증 결과는 TESTING.md 9절에 기록한다.

## 2. 화면과 탭 동작

| 탭 | 목록 내용 | 태그 선택 |
| --- | --- | --- |
| 자동완성 | 현재 항목의 영문 태그·한글 설명 검색 결과 또는 빈 항목에서 선택한 유형의 상위 태그 | 검색 결과는 `대체`, 유형 탐색 결과는 `+ 추가` |
| 북마크 | 저장된 태그 북마크 목록 | `+ 추가` |
| 기록 | 양쪽 편집기에서 사용한 태그를 최근 사용순으로 표시 | `+ 추가` |

1. 편집기 아래에 탭을 한 줄로 배치하고 한 번에 한 목록을 보여준다. 자동완성에서는 현재 항목 또는 유형 탐색 상태를, 추가할 수 있는 목록에서는 현재 삽입 대상인 `긍정` 또는 `부정`을 표시한다.
2. 북마크·기록 목록은 현재 입력 문자열로 필터링하지 않는다. 입력·삭제·붙여넣기, 긍정/부정 전환, 태그 추가만으로 선택한 목록 탭을 바꾸지 않는다. 자동완성 탭으로 돌아오면 현재 항목과 활성 사전의 결과를 표시한다.
3. 같은 화면 세션에서 탭마다 목록 스크롤 위치를 보관한다. 동일한 목록에 돌아올 때 해당 위치를 복원한다. 검색어·유형·사전 변경으로 자동완성 목록의 결과가 바뀌면 목록 처음부터 보여준다. 위치 복원은 프롬프트의 선택 범위나 편집창 스크롤을 바꾸지 않는다.
4. 북마크 등록·해제는 태그 행에서 제공한다. 기록은 기존 최근순, 최대 1,000개, 사용 횟수, 개별 삭제와 확인을 거치는 전체 삭제를 유지한다. 삭제는 기록에만 적용한다. 사전이 없거나 불러오는 중에도 북마크·기록에 저장된 태그 문자열을 사용할 수 있다.
5. 목록별 빈 상태를 구분한다. 자동완성에서는 사전 없음·준비 중·검색 중·결과 없음·입력 또는 유형 선택 안내를 해당 조건에 맞게 표시한다. 북마크와 기록은 각각 목록이 비었음을 표시한다.

## 3. 자동완성 안의 유형 필터

필터의 기본값은 `모든 유형`이다. 옵션은 활성 사전에 실제로 있는 유형으로 구성하고 현재 선택을 화면에 표시한다. `모든 유형`은 필터를 해제한다. 다른 사전으로 전환할 때는 `모든 유형`으로 돌아간다. 같은 사전의 교체나 앱 시작·백업 복원 후 선택 유형이 존재하지 않으면 필터를 해제한다.

| 편집 문맥 | 유형 선택 | 표시와 동작 |
| --- | --- | --- |
| 검색 가능한 항목에 입력 있음 | 모든 유형 또는 특정 유형 | 현재 항목을 검색하고 선택 유형으로 좁힌다. 최대 20개를 표시하며 `대체`를 제공한다. |
| 현재 항목이 비어 있음 | 특정 유형 | 해당 유형을 카운트 내림차순으로 최대 20개 표시한다. 동률은 기존 태그 정렬 규칙을 따른다. `+ 추가`를 제공한다. |
| 현재 항목이 비어 있음 | 모든 유형 | 태그·설명 입력 또는 유형 선택을 안내한다. |
| 선택이 구분자를 가로지르거나 수동 구문 보호에 해당함 | 모든 유형 또는 특정 유형 | 현재 항목을 보호한다. 대체 후보나 빈 항목의 유형 탐색 결과를 표시하지 않는다. |

빈 항목은 유효한 커서가 있는 쉼표·줄바꿈 항목에 공백 외의 문자가 없는 경우다. 수동 괄호·가중치 구문이나 그룹 내부는 별도 보호 문맥으로 판단한다. 예를 들어 `1girl, `에서 `일반`을 고르면 유형 목록을 탐색할 수 있고 `1girl, 푸른 눈`에서 같은 필터를 고르면 `푸른 눈`의 일치 결과만 표시한다.

입력 자동완성은 기존 120ms 대기, 한글 조합 중 검색, 검색 정규화와 정렬 규칙을 사용한다. 사전 검색과 유형 탐색은 Worker에서 실행한다. 최신 요청만 대기시키고 응답 적용과 클릭 처리에서 검색/탐색 구분, 사전, 유형, 현재 대상과 항목의 문맥을 확인한다. 탭·사전·유형 또는 원문이 바뀌는 동안 이전 후보를 선택할 수 없게 한다. 다른 탭에서 입력한 뒤 자동완성으로 복귀했을 때도 최신 문맥으로 확인한다.

## 4. 태그 적용과 편집 상태

- **대체**는 기존 자동완성 규칙을 따른다. 선택한 태그 원문으로 커서가 있는 항목만 바꾸고 양끝 공백·구분자·이웃 항목을 보존한다. `1girl, 푸른 눈, smile`의 가운데 항목을 선택하면 `1girl, blue eyes, smile`이 된다.
- **추가**는 현재 긍정/부정 편집기의 마지막 유효한 선택 범위에 기존 삽입 규칙을 적용한다. 커서만 있으면 그 위치에 넣고, 사용자가 텍스트를 선택해 두었으면 선택된 문자열을 대체한다. 범위가 유효하지 않으면 해당 편집기의 끝을 사용한다. 연속 추가는 직전 삽입 결과의 커서에서 이어진다.
- 현재 항목과 같은 자동완성 후보는 `일치`, 대상 초안에 이미 있는 태그는 `사용 중`으로 표시하고 버튼을 비활성화한다. 긍정·부정은 독립적으로 판정한다. 실제 적용에 성공할 때만 삽입 취소와 사용 기록을 한 번 갱신한다.
- 터치로 목록 탭을 바꾸거나 후보·북마크·기록을 조작할 때 편집기가 이미 초점을 갖고 있으면 이를 유지한다. 탭 전환만으로 키보드를 열거나 조합 중인 원문을 수정하지 않는다. 네이티브 유형 선택기를 열 때 브라우저가 초점을 옮겨도 편집기 선택 범위는 보존한다. 외부 키보드와 접근성 도구로 탭과 버튼에 접근할 수 있게 한다.
- 태그 적용은 명시적인 클릭에서만 실행한다. 누른 뒤 목록을 스크롤하거나 포인터가 취소되면 초안과 기록은 그대로 둔다. 조합 중 적용은 0.3.1의 입력 호스트 인계와 이전 이벤트 차단을 재사용한다. 조합 종료 이벤트를 기다리거나 `blur()`를 호출해 확정을 요구하는 흐름은 제거된 상태를 유지한다.

## 5. 모바일 배치와 상태 호환성

19.5:9 세로 휴대폰에서 키보드가 열린 경우에도 긍정/부정 전환, 편집창, 세 목록 탭과 태그 적용 버튼에 접근할 수 있게 한다. 필요하면 편집창을 키보드 표시 중에만 줄이고 목록을 스크롤한다. 가로 화면·좁은 분할 화면처럼 높이가 낮을 때는 본문 스크롤로 조작부와 목록에 도달할 수 있어야 한다. 탭과 버튼 사이에 가로 넘침을 만들지 않고, 긴 태그와 설명은 줄바꿈 또는 펼침으로 읽을 수 있게 한다. 실제 기기에서 보이는 후보 개수와 키보드 점유 높이는 화면 검증 때 확인한다.

신규 상태는 `자동완성`에서 시작한다. 기존 `settings.tab`의 `search`는 자동완성, `bookmarks`는 북마크, `history`는 기록으로 해석한다. 선택 탭과 유효한 유형 필터는 기존 설정 필드에 보관한다. 이전 버전에서 저장한 유형 필터는 활성 사전에서 유효할 때 통합 필터로 표시한다. 목록 스크롤은 현재 세션에서만 보관한다.

IndexedDB 및 JSON 백업 스키마 버전은 그대로 사용한다. 기존 백업의 초안·기록·북마크·저장 프롬프트·묶음을 유지하고, 사전 연결과 전체 복원 계약은 기존 명세를 따른다. 개인 CSV·프롬프트·백업 원문은 단말에서 처리하며 공개 검증에는 `samples/tags.example.csv`를 사용한다.

## 6. 구현 순서와 수용 기준

1. 편집기 아래에 공유 태그 목록과 세 탭을 구성하고, 측면 버튼·오버레이와 패널 전용 초점·위치·닫기 처리를 제거한다.
2. 기존 북마크·기록의 재사용·관리 동작을 연결하고 유형 필터와 검색/탐색 응답 구분을 적용한다. 기존 설정 및 백업과의 호환성을 확인한다.
3. 현재 문맥 검증, 삽입 취소, IME, 화면 크기, 목록별 스크롤을 검증한다. `pnpm test`와 `pnpm build`를 실행하고 [테스트 기록](TESTING.md)에 대상 버전·커밋·결과를 남긴다.

| ID | 수용 기준 |
| --- | --- |
| T01 | 편집기 아래에 세 탭과 한 목록이 표시된다. 입력·긍정/부정 전환·연속 삽입 후 선택 탭을 유지하며 같은 목록으로 복귀하면 스크롤 위치를 복원한다. |
| T02 | 입력이 있는 항목에서 유형으로 좁혀 대체하고, 빈 항목에서 유형을 선택해 상위 태그를 추가할 수 있다. 모든 유형의 빈 항목은 전체 사전을 나열하지 않는다. 보호 문맥과 이전 응답은 원문을 변경하지 않는다. |
| T03 | 사전이 없어도 북마크·기록으로 태그를 재사용할 수 있다. 연속 추가는 현재 대상과 커서에서 이어지고, 중복은 차단하며 북마크 등록·해제와 기록 삭제가 동작한다. |
| T04 | 조합 종료 이벤트 없이도 후보 클릭을 한 번 적용한다. 입력 직후와 목록 스크롤 후의 클릭, 취소된 스크롤, 대체 후 이어 입력에서 원문·기록·삽입 취소가 기존 규칙을 따른다. |
| T05 | 기존 JSON 스키마 1의 각 탭 값과 필터가 복원되고, 유효하지 않은 유형을 해제한다. 저장 프롬프트·초안 복원·복사·오프라인 기능도 회귀 확인한다. |
| T06 | Android Chrome의 세로·가로·좁은 화면에서 키보드를 올린 채 탭 전환, 목록 스크롤, 대체·추가와 이어 입력을 수행할 수 있다. 키보드 닫힘과 한글 중복 여부를 확인한다. 삼성 인터넷과 삼성 키보드의 동일 항목은 관리자 수동 검증에 기록한다. |

자동 테스트는 동작과 초점을 확인한다. 실제 키보드 표시와 한글 IME는 접근 가능한 Android 단말 또는 에뮬레이터에서 확인한다. 기존 0.3.1의 영문 Gboard 결과와 이전 삼성 검증 기록을 이번 변경의 결과로 사용하지 않는다. 실행하지 못한 기기·브라우저 조합은 미검증으로 남긴다.
