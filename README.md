# Generation Tag AutoComplete

채찍피티와 함께 제작하는 모바일 환경의 이미지 생성 프롬프트 작성 보조 툴.

개인 CSV를 가져와 영문 태그와 한글 설명을 검색하고, 긍정·부정 프롬프트를 작성·저장·복사하는 Android용 오프라인 PWA입니다. Android Chrome을 주 개발·검증 대상으로 삼고, 삼성 인터넷은 작업자/관리자가 직접 테스트해 문제점과 개선사항을 제안합니다. 이미지 생성 PC로의 전달과 원격 조작에는 사용자가 기존에 사용하는 원격 프로그램을 이용합니다.

## 현재 상태

2026-11-05 초기 구현을 진행했습니다. CSV 가져오기·검색, 긍정/부정 편집, 기록·라이브러리, JSON 백업/복원과 오프라인 PWA를 구현했습니다. 실제 검증 결과와 미검증 항목은 docs/TESTING.md에 기록합니다. 개인 CSV는 Git과 배포에서 제외합니다.

## 첫 버전의 범위

- 단말 안에서 CSV 가져오기, 사전 선택·교체·삭제, 태그·설명 부분 문자열 검색.
- 별도 검색창과 긍정·부정 원문 편집기. 태그 칩은 제공하지 않습니다.
- `검색 / 기록` 전환 탭에서 최근 사용 태그 확인과 재사용.
- 이미 사용 중인 태그 표시와 같은 편집기 안의 중복 삽입 방지.
- 초안 자동 저장, 이름을 붙인 프롬프트, 즐겨찾기와 태그 묶음.
- JSON 백업·전체 복원, 오프라인 재실행, 앱 전환 후 초안 복원.
- 개인 CSV·검색어·프롬프트의 서버 전송 없이 동작.

## 개인 데이터

개인 CSV는 앱 화면의 파일 선택으로 가져옵니다. 소스 폴더에 있는 CSV를 앱이 자동으로 수집하거나 배포물에 포함해서는 안 됩니다. CSV가 없는 상태에서도 원문 편집·저장·복사를 사용할 수 있도록 구현합니다.

CSV·TSV는 기본적으로 Git에서 제외하고, 공개용 합성 예제인 `samples/tags.example.csv`만 명시적으로 허용합니다. 사용자 백업과 가져오기·내보내기 데이터도 관리 대상에서 제외합니다. 첫 커밋과 배포 전에 실제 포함 파일 목록을 확인합니다.

## 라이선스와 참고

프로젝트 코드는 [MIT](LICENSE)를 사용합니다. EreNodes의 CSV 자동완성 방식을 참고하며, 실제 코드 재사용 시 [외부 저작물 고지](THIRD_PARTY_NOTICES.md)에 출처와 고지를 유지합니다. 개인 CSV는 프로젝트 코드 라이선스의 배포 대상으로 자동 편입하지 않습니다.

## 실행과 검증

Node.js 24, pnpm 11.25.0을 사용합니다. 의존성은 잠금 파일로 고정합니다.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
pnpm test
pnpm build
pnpm preview
```

배포물은 dist만 사용합니다. main에 푸시하면 GitHub Actions가 테스트·빌드 후 Pages에 배포합니다. Pages 소스는 GitHub Actions로 설정합니다. 사전 없이도 편집할 수 있으며 ‘사전 관리 → 공개 예제로 시작’으로 11행 합성 사전을 시험할 수 있습니다.
