# Generation Tag AutoComplete

채찍피티와 함께 제작하는 모바일 환경의 이미지 생성 프롬프트 작성 보조 툴.

개인 CSV를 가져와 영문 태그와 한글 설명을 검색하고, 긍정·부정 프롬프트를 작성·저장·복사하는 Android용 오프라인 PWA입니다. Android Chrome을 주 개발·검증 대상으로 삼고, 삼성 인터넷은 작업자/관리자가 직접 테스트해 문제점과 개선사항을 제안합니다. 이미지 생성 PC로의 전달과 원격 조작에는 사용자가 기존에 사용하는 원격 프로그램을 이용합니다.

## 현재 상태

2026-11-06 앱 0.2.0의 초기 구현과 관리자 기능 검증을 마무리했습니다. 갤럭시 S25·탭 A11+에서 Android Chrome과 삼성 브라우저의 수동 체크리스트 수행 및 JSON 내보내기·불러오기·잘못된 양식 거절이 정상 동작한다는 관리자 보고를 받았습니다. 환경과 검증 범위, 추가 진단 항목은 [테스트 기록](docs/TESTING.md)에 구분해 기록합니다. 개인 CSV는 Git과 배포에서 제외합니다.

후속 UI/UX 개선의 [작업 명세](docs/UI_UX_IMPROVEMENTS.md)를 작성했습니다. 조합 중 자동완성, 저장 프롬프트 미리보기·개별 복사, 측면 버튼 태그 찾기는 구현 대기 상태이며 현재 배포 앱 0.2.0의 기능과 구분합니다.

## 첫 버전의 범위

- 단말 안에서 CSV 가져오기, 사전 선택·교체·삭제, 태그·설명 부분 문자열 검색.
- 긍정/부정 전환 편집기와 현재 쉼표·줄바꿈 항목의 실시간 자동완성.
- 고정 주요 메뉴, 접이식 태그 찾기의 북마크·유형 탐색·기록 탭.
- 이미 사용 중인 태그 표시와 같은 편집기 안의 중복 삽입 방지.
- 초안 자동 저장, 이름을 붙인 프롬프트, 즐겨찾기와 태그 묶음.
- JSON 백업·전체 복원, 오프라인 재실행, 앱 전환 후 초안 복원.
- 개인 CSV·검색어·프롬프트의 서버 전송 없이 동작.

## 개인 데이터

개인 CSV는 앱 화면의 파일 선택으로 가져옵니다. 소스 폴더에 있는 CSV를 앱이 자동으로 수집하거나 배포물에 포함해서는 안 됩니다. CSV가 없는 상태에서도 원문 편집·저장·복사를 사용할 수 있습니다.

CSV·TSV는 기본적으로 Git에서 제외하고, 공개용 합성 예제인 `samples/tags.example.csv`만 명시적으로 허용합니다. 사용자 백업과 가져오기·내보내기 데이터도 관리 대상에서 제외합니다. 커밋과 배포 전에 실제 포함 파일 목록을 확인합니다.

## 라이선스와 참고

프로젝트 코드는 [MIT](LICENSE)를 사용합니다. EreNodes의 CSV 자동완성 방식을 참고하며, 실제 코드 재사용 시 [외부 저작물 고지](THIRD_PARTY_NOTICES.md)에 출처와 고지를 유지합니다. 개인 CSV는 프로젝트 코드 라이선스의 배포 대상으로 자동 편입하지 않습니다.

## 실행과 검증

Node.js 24, pnpm 11.25.0을 사용합니다. 의존성은 잠금 파일로 고정합니다.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
pnpm test
pnpm build
pnpm preview
```

배포물은 dist만 사용합니다. main에 푸시하면 GitHub Actions가 테스트·빌드 후 Pages에 배포합니다. Pages 소스는 GitHub Actions로 설정합니다. 사전 없이도 편집할 수 있으며 ‘사전 관리 → 공개 예제 가져오기’로 11행 합성 사전을 시험할 수 있습니다.

## 사용 흐름

[앱 열기](https://cr0sseye.github.io/generation-tag-autocomplete/) → 사전 관리에서 CSV 가져오기 → 편집에서 긍정/부정 선택 → 태그 또는 한글 설명 입력 → 자동완성 후보로 현재 항목 대체 → 저장 또는 복사. 괄호·가중치 구문은 자동 대체하지 않습니다.

태그 찾기를 펼치면 북마크·유형별 상위 20개·사용 기록을 볼 수 있습니다. 유형 탐색은 자동완성의 검색 범위를 바꾸지 않습니다.
